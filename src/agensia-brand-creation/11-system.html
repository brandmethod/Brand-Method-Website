Why the last six did not survive

The descriptive line and the endorsement variant are real needs met elsewhere: the descriptor is set beside the lockup inside the layout, not inside the lockup. Symbol-right, spaced, tiled and two-tone all failed for the same reason · they are a second lockup to govern, and Brand Book 3.3 permits three configurations and no others.

The rule the approved three share

Identical proportion. The symbol is the same optical size relative to the cap height in every one of them, so the identity holds across digital, print and spatial use without anyone deciding anything.

The rule that governs both top rows

One drawing per size band, not one drawing scaled. Below 48 px the contour count reduces; below 24 px the system substitutes the solid form. A single vector used everywhere looks wrong at both ends of the range.

Green is not a state

The green treatment is the brand mark and one call to action per surface. It must never carry a success, a warning or a system state · the interface has its own status scale for that, and shape carries it alongside colour.

Confirmed, not provisional
