# assets/fonts/

Empty by design. The book loads Switzer, Instrument Sans and JetBrains Mono
from their CDNs, so it needs a connection to set in the correct faces.

Drop the six `.woff2` files listed in `../../css/fonts-local.css` here and
follow the two-step switch in that file to make the book fully offline.

| Family | Source |
|---|---|
| Switzer | https://www.fontshare.com/fonts/switzer |
| Instrument Sans | https://fonts.google.com/specimen/Instrument+Sans |
| JetBrains Mono | https://www.jetbrains.com/lp/mono/ |

All three are free to self-host; check each licence before redistributing the
folder outside IAQ and its authorised partners.
